# Fuente pixel original

Coloca aquí la fuente de los juegos originales con el nombre:

- `pokemon-gb.woff2` (preferido)
- `pokemon-gb.ttf` (alternativa)

`css/base.css` ya la carga vía `@font-face` con el nombre `PixelPokemon` y hace
fallback automático a una fuente monospace mientras no exista el archivo. No
hace falta tocar ningún otro archivo.
